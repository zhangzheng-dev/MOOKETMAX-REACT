## 测试详情

### 1. 后端分页 API

**接口**: `GET /api/v1/merchant/2421879288627542016/products`

**参数**:
- `type`: offer
- `category`: 牛
- `page`: 1
- `pageSize`: 10

**响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "products": [...],
    "currentPage": 1,
    "pageSize": 10,
    "totalPages": 2,
    "totalCount": 16
  }
}
```

### 2. 展开/收起交互

**测试步骤**:
1. 打开 APP → 首页
2. 点击分类进入搜索页
3. 搜索"牛肉"找到商家
4. 点击商家进入详情页
5. 滚动找到有展开箭头的卡片
6. 点击箭头展开卡片
7. 再次点击箭头收起卡片

**验证点**:
- 展开时箭头从右箭头变为下箭头
- 展开时显示完整产品描述文本
- 收起时箭头颜色变为 BFCAC8
- 收起时只显示摘要信息
