# 商家详情页页面元素

## 1. 顶部导航栏 (TopAppBar)
| 元素 | 说明 |
|------|------|
| 返回按钮 | `ic_back_arrow` 图标，24dp |
| 商家Logo | `ic_merchant_logo`，24dp x 24dp |
| 商家名称 | 20sp，Medium，#171D1C |
| 商家标签 | 背景 #244C56，11sp，白色文字，如"知名商家" |
| 皇冠图标 | `ic_merchant_crown`，知名商家时显示 |

## 2. 数据看板 (DataDashboard)
| 元素 | 说明 |
|------|------|
| 近2日报盘数 | 标题 10sp，数值 16sp SemiBold |
| 产品数 | 同上 |
| 工厂数 | 同上 |

## 3. Tab选择区域 (TabSection)
| 元素 | 说明 |
|------|------|
| 报盘 Tab | 选中时 14sp SemiBold + 3dp 下划线 |
| 求购 Tab | 同上 |
| 综合推荐 Tab | 14sp |
| 价格 Tab | 带上下箭头图标，排序时变色 |

## 4. 筛选区域 (FilterSection)
| 筛选类型 | 元素 |
|----------|------|
| 国家厂号 | FilterChip，选中时绿框+绿字 |
| 地区 | 同上 |
| 产品 | 同上 |
| 货物类型 | 同上 |
| 饲养方式 | 同上 |

## 5. 报盘卡片 (OfferCardNew)
| 元素 | 说明 |
|------|------|
| 产品名称行 | "产品名 国家厂号"，16sp Medium |
| 价格 | ¥价格 /kg，16sp SemiBold #006A61 |
| 展开箭头 | `ic_arrow_down`，点击展开/收起 |
| 标签 | 地区(绿底)、货物类型、饲养方式、特殊标签 |
| **展开后显示员工报价卡片列表** | |

## 6. 员工报价卡片 (EmployeeOfferCard)
| 元素 | 说明 |
|------|------|
| 头像 | `ic_avatar`，18dp |
| 用户昵称 | 14sp Medium |
| 联系电话 | 12sp，#9DA4A3 |
| 重量 | 值 16sp SemiBold + 单位 10sp，整数不显示小数 |
| 价格 | ¥价格/kg，16sp SemiBold #006A61 |
| 发布时间 | 11sp，格式："今天 HH:mm" / "昨天 HH:mm" / "MM-dd HH:mm" |
| 标签 | 地区、货物类型、饲养方式、特殊标签 |
| 分隔线 | 0.5dp，#006A61 5%透明度 |
| 操作按钮 | 查看原文、添加微信(灰色)、拨打电话(绿色) |

## 7. 底部抽屉 (ModalBottomSheet)
